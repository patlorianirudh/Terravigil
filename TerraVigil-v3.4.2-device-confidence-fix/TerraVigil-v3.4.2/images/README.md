Place detection JPEG/PNG/WebP files here when they are available on the ground computer.
The Firebase image_path may be a filename or an onboard path. Only files inside
this folder (or DETECTION_IMAGE_DIR) can be displayed by the app. A path on the
Jetson Nano 4GB does not transfer image bytes. A public HTTPS image_url also works.
Keep serviceAccountKey.json in backend, never in this image folder.
